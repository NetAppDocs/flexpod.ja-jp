= まとめ
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
FlexPod Edgeをソフトウェアで定義されるストレージとともに展開することで、お客様はエッジでエンタープライズデータサービスを利用するための実用的な道筋を得ることができます。このアーキテクチャは、Ciscoのコンパクトで集中管理型のUnified EdgeプラットフォームとONTAPの成熟したデータサービスを組み合わせることで、データが作成および操作されるローカルワークロードをサポートできる単一シャーシ内でのソフトウェアで定義されるストレージを実現します。

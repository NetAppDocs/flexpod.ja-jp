[[cisco-ucs-x-series-modular-system]]
== Cisco UCS X-Series モジュラーシステム

Cisco UCS X シリーズ モジュラー システムは、適応性があり将来を見据えた設計の Cisco UCS X9508 サーバー シャーシから始まります。シャーシには、Cisco UCS インテリジェント ファブリック モジュールと他のテクノロジー向けの Cisco UCS X-Fabric テクノロジーを備えた統合イーサネット ファブリックが搭載されています。シャーシ後部上部には、シャーシを上流の Cisco UCS 6400、6500、および UCS 6600 シリーズ ファブリック インターコネクトに接続する 2 つのインテリジェント ファブリック モジュールがあります。

Cisco UCS X シリーズの機能と特徴の概要については、link:https://www.cisco.com/c/en/us/products/collateral/servers-unified-computing/ucs-x-series-modular-system/ucs-x-series-modular-system-aag.html["Cisco UCS X シリーズ モジュラー システムの概要"^]を参照してください。

Cisco UCS X215c M8、Cisco UCS X210c、および Cisco UCS X410c コンピュートノードは、単一のフォームファクタでコンピューティング密度、ストレージ容量、および拡張性を提供することにより、ブレードサーバーとラックサーバーの両方の機能を実現します。

Cisco UCS X440p PCIe ノードは、Cisco UCS X9416 X-Fabric Module を使用して PCIe Gen 4.0 の GPU の追加をサポートしています。Cisco UCS X580p PCIe ノードは、Cisco UCS X9516 X-Fabric Module を使用して PCIe Gen 5.0 の GPU の追加をサポートしています。

Cisco UCS X-Series Modular System解決策コンポーネントの詳細については、上記のセクションにあるこれらの各コンポーネントの技術仕様を参照してください。


NOTE: Cisco UCS X シリーズ モジュラー システムの完全な技術仕様については、以下のリンクを参照してください：link:https://www.cisco.com/c/en/us/products/servers-unified-computing/ucs-x-series-modular-system/datasheet-listing.html["Cisco UCS X-Series モジュラーシステム"^]



[[cisco-ucs-x-series-direct-options]]
== Cisco UCS X シリーズのダイレクトオプション

Cisco UCS X-Series Directは、Cisco UCS Fabric Interconnect 9108 100GのペアとCisco UCS X9508シャーシおよびCisco UCS X-Seriesコンピュートノードを統合し、UCS X-Series Directソリューションを提供する新しいアーキテクチャです。

Cisco UCS X シリーズの機能と特徴の概要については、link:https://www.cisco.com/c/en/us/products/collateral/servers-unified-computing/ucs-x-series-modular-system/ucs-x-series-direct-aag.html["Cisco UCS X シリーズ ダイレクトの概要"^]を参照してください。

Cisco UCS X-Series Directは、以下のコンポーネントで構成されています。

* Cisco UCS 9108 100G ファブリック インターコネクト
* Cisco UCS X9508シャーシ
* Cisco UCS Xシリーズコンピュートノード
* オプションコンポーネント：
+
** PCIe ノードと X-Fabric モジュール
** 2番目の Cisco UCS X9508 シャーシ（X シリーズコンピューティングノードおよび Cisco UCS 9108-100G インテリジェントファブリックモジュール搭載）と最大 4 台の C シリーズラックサーバー




これらの各コンポーネントの技術仕様の詳細については、上記のセクションを参照してください（Cisco UCS X-Series Direct ソリューションコンポーネント）。


NOTE: Cisco UCS X-Series Direct の完全な技術仕様については、以下のリンクを参照してください： https://www.cisco.com/c/en/us/products/collateral/servers-unified-computing/ucs-x-series-modular-system/ucs-x-series-direct-ds.html["Cisco UCS X シリーズダイレクトデータシート"]。

link:https://www.cisco.com/c/dam/en_us/about/doing_business/legal/service_descriptions/docs/solution-support-smart-total-care.pdf["Cisco 解決策サポート"^] は、Cisco のみ、または Cisco と Solution Support Alliance Partners の両方からのハードウェアおよびソフトウェアを含む Cisco ソリューションに適用される技術サポートサービスの提供内容であり、Cisco 製品およびサードパーティベンダー（Solution Support Alliance Partner（s））が提供する製品のみで構成されます。

Cisco は、link:https://www.cisco.com/c/en/us/support/web/tac/technical-services-resource-guide.html["技術支援センター"]を通じて複雑なお客様環境をサポートします。Cisco 解決策サポート契約により、お客様は TAC エンジニアのチームにアクセスできます。このチームは、ソリューション内で発生した問題に対する主要な連絡窓口となるだけでなく、ソリューションを構成するハードウェアおよびソフトウェアの製品サポートも提供します。

Cisco はlink:https://www.tsanet.org/cisco-tsanet-case-study/["TSANetパートナープログラム"^]フレームワークを活用して、Solution Support Partners を TSANet Connect システム上のプライベートグループにオンボーディングします。TSANet Connect は、サポートエンジニアがパートナーの技術チームと連携するための統一された方法を提供し、パートナーとの非公式な連携によって生じる摩擦をなくし、効率的なコミュニケーションと迅速な問題解決を実現します。

= FlexPod データセンター技術仕様
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
FlexPodプラットフォームは、ベストプラクティスに基づいた事前設計済みのデータセンターアーキテクチャであり、Cisco Unified Computing System（Cisco UCS）、Cisco NexusおよびMDS（FC用）ファミリーのスイッチ、およびNetAppストレージコントローラ（AFF、ASA、FAS、またはAFXシステム）上に構築されています。

FlexPodは、さまざまな仮想化ハイパーバイザー、ベアメタルオペレーティングシステム、コンテナ化環境、およびエンタープライズワークロードを実行するのに適したプラットフォームです。FlexPodは、ベースライン構成を提供するだけでなく、さまざまなユースケースや要件に対応できるよう、柔軟にサイズ調整と最適化を行える利点も備えています。


NOTE: 完全な FlexPod 構成を注文する前に、これらの技術仕様の最新バージョンについては http://www.netapp.com/us/technology/flexpod["NetApp FlexPod ホームページ"^]を参照してください。

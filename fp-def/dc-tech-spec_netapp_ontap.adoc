= NetApp ONTAP
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
NetApp ONTAPソフトウェアは、AFF、ASA、FAS、およびAFXストレージシステム上で動作するオペレーティングシステムです。ONTAPは拡張性の高いストレージ アーキテクチャを提供し、業務の中断を伴わない運用、中断を伴わないアップグレード、および俊敏なデータインフラストラクチャを実現します。ONTAP Oneライセンス モデルにより、すべてのエンタープライズデータサービスが単一のパッケージに含まれるため、導入と管理が簡素化され、高度な機能への完全なアクセスが可能になります。ONTAPは、レプリケーションおよびディザスタリカバリのためのSnapMirrorや、アプリケーション整合性のあるバックアップとリストアのためのSnapCenterなどのテクノロジーを通じて、堅牢なデータ保護を提供します。また、Autonomous Ransomware Protectionや暗号化などの組み込みのセキュリティ機能を備え、最新の脅威からデータを保護します。さらに、ONTAPはSnapMirror CloudやS3ベースのレプリケーションなどの機能によってシームレスなハイブリッドクラウド統合を実現し、一貫性と制御を維持しながらオンプレミスおよびクラウド環境間でのデータ移動を可能にします。

ONTAPの詳細については、 https://www.netapp.com/ontap-data-management-software/["ONTAP データ管理ソフトウェア"^]製品ページを参照してください。

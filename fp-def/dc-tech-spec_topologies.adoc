== Cisco UCS X シリーズモジュラーシステムおよび C シリーズラックサーバー（FC および IP ベース SAN 搭載）

以下の図は、IPベースのiSCSI構成に対応した、XシリーズモジュラーシステムとCシリーズラックサーバーを備えたFlexPod データセンターの例を示しています。このトポロジーはNFSとNVMe-TCPもサポートしています。

image:dc-tech-spec_image15.png["FlexPod IPベースのiSCSI接続のためのデータセンター"]

次の図は、MDSスイッチを使用したFCベースのSAN構成向けに、XシリーズモジュラーシステムとCシリーズラックサーバーを組み合わせたFlexPod データセンターの例を示しています。上記のトポロジーはNFSおよびFC-NVMeもサポートしています。

image:dc-tech-spec_image16.png["FlexPod FCベースのSAN接続に対応したデータセンター"]

上記のトポロジーにおける接続要件は以下のとおりです。

* AFF クラスタ接続性：2 ノード AFF クラスタ構成の場合、クラスタスイッチを使用せずに、コントローラをケーブルで直接接続できます。
* ストレージイーサネット接続：NetApp ストレージコントローラは、Cisco Nexus スイッチに直接接続する必要があります。
* Cisco UCS X9508シャーシは、Cisco UCSX-I-9108-100G IFMを使用してファブリックインターコネクトに接続します。Cisco UCSX-I-9108-25G IFMは、シャーシとファブリックインターコネクトを接続するために使用される4x25Gブレークアウトケーブルと併用することもできます。
* Cisco UCS X シリーズモジュラーコンピューティングノードには Cisco VIC が搭載されており、どちらの IFM とも併用可能です。
* Cisco UCS CシリーズラックサーバーにはCisco VICが搭載されており、ファブリック インターコネクトに接続します。
* 仮想ポートチャネル（vPC）は、Cisco Nexus スイッチを NetApp ストレージコントローラーに接続し、Cisco UCS ファブリック インターコネクトを Cisco Nexus スイッチに接続するために必要です。
* FC接続要件：
+
** NetApp ストレージコントローラは、SAN接続のために32Gbps FC接続を使用してCisco MDSスイッチに接続されています。
** Cisco UCS ファブリック インターコネクトは、SAN 接続用に単一ポート チャネルとして構成された 32 Gbps FC 接続を使用して Cisco MDS スイッチに接続します。




IP ベースの SAN のみ、FC ベースの SAN のみ、またはワークロードのレイテンシとスループット要件に対応するために異なるプロトコルを採用する両方の実装を選択できます。NVMe over Fabricプロトコルは、より効率的なデバイス接続、コマンドセット、およびCPU使用率の低減により、低遅延と1秒あたりの入出力操作数（IOPS）の向上を実現します。


NOTE: 上記のサンプルトポロジは、NetApp AFF を使用した X シリーズモジュラーおよび C シリーズラックサーバーソリューション構成を示しています。ただし、同じトポロジは NetApp ASA および FAS にも使用できます。

この構成の詳細については、link:https://www.cisco.com/c/en/us/td/docs/unified_computing/ucs/UCS_CVDs/flexpod_m7_imm_vmware_design.html#PhysicalTopology["FlexPod データセンター（Cisco UCS M7 IMM、VMware vSphere 8.0、NetApp ONTAP 9.12）設計ガイド"^]を参照してください。



[[cisco-ucs-x-series-direct-with-direct-attached-fc-and-ip-based-san]]
== Cisco UCS X-Series Direct（FCおよびIPベースSANを直接接続）

次の図は、FlexPod データセンターのIPベースおよびFCベースのSAN向けのUCS X-Series DirectおよびダイレクトアタッチドASAのサンプルトポロジーを示しています。

image:dc-tech-spec_image14.png["UCS X-Series ダイレクトおよびダイレクトアタッチ ASA の IP ベースおよび FC ベースの SAN トポロジー"]

このトポロジーの接続要件は次のとおりです：

* ASA クラスタ接続性：2 ノードの ASA クラスター構成の場合、クラスタースイッチを使用せずに、コントローラーをケーブルで直接接続できます。
* ストレージイーサネット接続：NetAppストレージコントローラは、組み込みのファブリックインターコネクトに直接接続できます。ASA の 2 つのストレージコントローラは、FI A および FI B によって提供される 2 つの独立した IP SAN ファブリックに接続されています。
* FIネットワークのアップリンク接続：IPベースのSAN接続の場合、アップリンクNexusスイッチはSANデータパスには関与しません。SAN IOは、FI AまたはFI Bへの接続を使用して、UCS ComputeノードからASAストレージへ直接送信されます。その結果、VLANとvPCをサポートする既存のトップオブラックスイッチを使用して、FlexPod SANソリューション環境への外部ネットワーク アクセスを提供できます。
* FCベースのSAN接続の場合、UCS FI（FC）ポートをブレークアウトポートとして構成する必要があります。
* Cisco UCS を FC ベースの SAN ソリューションで使用する場合は、FC スイッチング モードに設定する必要があります。


Cisco UCS X-Series Directは、外部ファブリックインターコネクトではなく内蔵ファブリックインターコネクトを使用することで、通常のX-Seriesと同様にスイッチ接続ストレージを利用することもできます。

この構成の詳細については、 https://www.netapp.com/pdf.html?item=/media/135828-flexpod-san-ucs-xdirect-asa-nva-deploy-guide.pdf["Cisco UCS X-Series DirectおよびNetApp ASAを使用したFlexPod SAN解決策"^]を参照してください。

[NOTE]
====
上記のサンプルトポロジーは、NetApp ASA を使用した直接接続ストレージの解決策を示しています。ただし、同じトポロジーは NetApp AFF および FAS にも使用できます。

IPベースの直接接続型NASストレージ構成でNetApp AFFまたはFASストレージを使用する場合、アップリンクのNexusスイッチは、特定の障害シナリオに対応できるように適切に構成する必要があります。詳細な設定情報については、下記のリンクを参照してください。

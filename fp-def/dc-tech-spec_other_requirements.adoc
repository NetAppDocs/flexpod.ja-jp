= その他の要件
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
FlexPod データセンターの追加要件は次のとおりです：

* VMware ESXi をハイパーバイザーとして使用する場合は、link:https://compatibilityguide.broadcom.com/["Broadcom互換性ガイド"] を参照して、ハードウェアおよびソフトウェアコンポーネントがサポートされていることを確認してください。
* OpenShiftベースのデプロイメントの場合は、OpenShiftと互換性のある必要なハードウェアおよびソフトウェアコンポーネントが揃っていることを確認してください。詳細については、link:https://catalog.redhat.com/en/search["OpenShift カタログ"]を参照してください。
